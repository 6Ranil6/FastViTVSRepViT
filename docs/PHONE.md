# Как запустить сравнение моделей на Galaxy A34 5G

0. Сначала проделать всё что описано в `TRAIN_EVAL.md`

## Установить приложение

1. Скачайте и установите [Android Studio для Mac](https://developer.android.com/studio).
2. Откройте Android Studio, нажмите **Open** и выберите папку `android` внутри `fastvit-repvit-coursework`.
3. Если при открытии проекта Android Studio предложит установить недостающие компоненты Android SDK, нажмите **Install**.
4. На Galaxy A34 откройте **Настройки → Сведения о телефоне → Сведения о ПО** и нажмите **Номер сборки** семь раз.
5. В **Настройки → Параметры разработчика** включите **Отладка по USB**.
6. Подключите телефон к Mac USB-кабелем и нажмите **Разрешить** в запросе на экране телефона.
7. В Android Studio дважды нажмите **Shift**, введите **Sync Project with Gradle Files** и нажмите **Enter**.
8. Дождитесь окончания синхронизации и выберите **Galaxy A34** (может отображаться как **SM-A346E**) в выпадающем списке слева от зелёной кнопки **▶ Run** на верхней панели.
9. Нажмите **▶ Run**, чтобы установить или обновить приложение на телефоне.
10. Дождитесь, пока приложение откроется на телефоне.

## Запустить замеры и сохранить результат

В каждом испытании приложение выполняет 30 прогревочных вызовов на модель, затем дважды измеряет время `forward` на каждом из 102 фото. По 204 замерам для каждой модели рассчитываются p50 и p95, а точность проверяется на тех же 102 фото. Подготовка изображений выполняется до запуска таймера.

Если у Вас уже есть CSV с замерами на одном фото, перенесите их в отдельную папку перед сбором новой сводки.

11. В приложении выберите **1** в списке **Потоки CPU** и оставьте флажок **Сначала RepViT** снятым.
12. Нажмите **Сравнить модели** и дождитесь сообщения **«Готово»**.
13. Нажмите **Сохранить CSV** и сохраните файл в папку **Download / Загрузки** на телефоне.
14. Включите флажок **Сначала RepViT** и повторите шаги 12–13 один раз.
15. По очереди выберите **2** и **4** потока и в каждом режиме повторите шаги 12–14, начиная со снятого флажка **Сначала RepViT**.
16. В Android Studio откройте **View → Tool Windows → Device Explorer**, выберите **Galaxy A34** и перейдите в `/sdcard/Download`.
17. Нажмите правой кнопкой на каждый из 6 CSV с новыми замерами и через **Save As** сохраните их в папку `report_phone/` в корне проекта на Mac, создав её при необходимости.
18. Откройте терминал в корне проекта и выполните `.venv/bin/python -m coursework.mobile_report report_phone/*.csv`.
19. Выполните `.venv/bin/python -m coursework.mobile_markdown`, чтобы обновить таблицу и диаграммы мобильных замеров в `report.md`.
20. Откройте [report.md](../report.md#мобильные-замеры), чтобы посмотреть сводку по обеим моделям для 1, 2 и 4 потоков.
